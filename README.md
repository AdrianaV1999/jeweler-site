# Jewelry E-Commerce Website

A responsive e-commerce website for selling jewelry, built with **React.js** + **Vite** and styled using **Tailwind CSS**. The site includes features for filtering, sorting, searching and managing products in the cart.

## Live Preview

Check out the live app here:  
https://adrianav1999.github.io/jeweler-site/

## Features

- Browse and search jewelry products by category or keywords.
- Filter and sort products.
- Add products to the cart and adjust quantities.
- Place orders and view past orders.
- Responsive design for desktop and mobile devices.

## Components

- **Navbar.jsx** — Handles navigation between pages.
- **Hero.jsx** — Main introduction section.
- **ProductItem.jsx** — Displays individual products.
- **BestSeller.jsx / LatestCollection.jsx / RelatedProducts.jsx** — Highlights products.
- **CartTotal.jsx** — Shows total price in the cart.
- **Footer.jsx / Newsletter.jsx / OurPolicy.jsx / Title.jsx / Search.jsx** — Layout and utility components.

## Pages

- **Home** — Landing page with featured products.
- **Collection** — Product catalog with filters and sorting.
- **Cart** — Shopping cart.
- **PlaceOrder** — Checkout page.
- **Orders** — User's past orders.
- **Product** — Product details page.
- **About** — Company information.
- **Contact** — Contact form.
- **Login** — User login page.

## Technologies Used

- **React.js + Vite** for building the frontend interface.
- **React Router** for handling navigation between pages.
- **React Context API** for managing global state.
- **Tailwind CSS** for styling components.

## Installation / How to Run

To run this project locally:

1. Clone the repository:

   #### `git clone https://github.com/AdrianaV1999/jeweler-site.git`

2. Navigate into the project folder:

   #### `cd jeweler-site`

3. Install dependencies:

   #### `npm install`

4. Start the development server:

   #### `npm run dev`

This will start the app locally at: `http://localhost:5173` (default Vite port)

## Jewelry E-Commerce Website

This is a **React.js** e-commerce website for selling jewelry, built with **Vite**. It includes functionalities for **filtering, sorting, searching, and adding products to the cart**. The site has pages for **home, collection, about, contact, checkout, and my orders**. The design is **responsive** and built using **Tailwind CSS**.  

### Project Structure:
- **`src/components`** – Reusable components (`Navbar.jsx`, `Hero.jsx`, `ProductItem.jsx`, etc.)  
- **`src/context`** – Global state management (`ShopContext.jsx`)  
- **`src/pages`** – Main pages (`Home.jsx`, `Collection.jsx`, `Cart.jsx`, etc.)  
- **`src/pics`** – Images used in the project  

### Technologies Used:
- **React.js & Vite** for fast and efficient development  
- **Context API** for state management  
- **Tailwind CSS** for styling
